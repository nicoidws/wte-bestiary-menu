# Bestiario en el menu / Bestiary Menu

Mod comunitario para **Welcome to Elderfield**. Agrega un acceso directo a la
categoria Bestiario de la enciclopedia existente en el menu del juego.

Community mod for **Welcome to Elderfield**. Adds a shortcut to the existing
encyclopedia's Bestiary category in the in-game menu.

## Requisitos / Requirements

- WTE Mod Loader.
- El menu personalizado `HorrorMainMenu` y `CGMZ_Encyclopedia` deben estar
  activos en el juego.
- The custom `HorrorMainMenu` and `CGMZ_Encyclopedia` plugins must be enabled.

Este mod no incluye ni crea entradas de enemigos; abre el bestiario ya provisto
por el juego.

This mod does not include or create enemy entries; it opens the bestiary already
provided by the game.

## Instalacion / Installation

### Vortex o instalacion manual / Vortex or manual installation

Instala el archivo ZIP con Vortex, o extrae la carpeta `Bestiario_Menu` dentro
de la carpeta `mods` del juego. Comprueba que la carpeta activa se llame
`Bestiario_Menu` y no empiece con `!`.

Install the ZIP with Vortex, or extract the `Bestiario_Menu` folder into the
game's `mods` folder. Make sure the active folder is named `Bestiario_Menu` and
does not start with `!`.

Reinicia el juego despues de instalar o actualizar el mod.

Restart the game after installing or updating the mod.
